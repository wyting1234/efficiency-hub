    Core Skills

    核心学习技巧

    ✅ 不要死背分录，优先吃透经济实质与准则原理；
    ✅ 按考纲等级分配时间：1 级了解、2 级熟悉、3 级主攻 4 分水平；
    ✅ 刷题三层递进：章节例题 → 章节综合题 → 跨章节真题；
    ✅ 拒绝抄书大笔记，只做知识树骨架 + 陷阱清单；
    ✅ 每周固定复盘薄弱池，周期性滚动复习。

    Three Rounds

    三轮完整复习规划

    第一轮：搭建知识树 + 初步打分
    逐章拆解多级标题，闭卷复述，完成基础习题，消灭 0 分空白点，目标大多达到 2‑3 分。不要死磕冷门最难变形。

    第二轮：薄弱池攻坚（提分最重要阶段）
    筛选 ≤3 分知识点重学教材细节，集中训练主观大题，刻意练习跨章节融合题型，完善错题陷阱笔记。核心 3 级考点稳定冲到 4 分。

    第三轮：整套限时模拟 + 短板滚动复盘
    严格 3 小时整套真题模拟；不再大面积学习新知识，反复回看低分条目与陷阱笔记，保持做题手感。

    Daily Routine

    每日固定执行流程

    1. 阅读教材，梳理多级标题知识树
    2. 合上书本逐级复述，标记断点漏洞
    3. 完成配套习题，录入打分台账
    4. 低分知识点记入陷阱笔记
    5. 每周复盘薄弱条目，复测掌握分数，达标移出薄弱池

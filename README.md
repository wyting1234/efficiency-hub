# 个人效率中心 - 云端同步版

## 快速开始

### 1. 启动同步服务器

双击运行 `server/启动同步服务器.bat`

服务器启动后会显示：
- 本机访问地址：`http://localhost:3456`
- 局域网访问地址：`http://你的IP:3456`（手机用这个）

### 2. 电脑上使用

浏览器打开 `http://localhost:3456`

### 3. 手机上使用

确保手机和电脑连接同一个 WiFi，用手机浏览器打开局域网地址（如 `http://192.168.x.x:3456`）

### 4. 数据自动同步

- 打开任意工具录入数据，2 秒后自动同步到云端
- 每 30 秒自动从云端拉取最新数据
- 切换到其他标签页再回来时也会自动同步
- 侧边栏底部有同步状态指示器，点击可手动同步

## 文件结构

```
efficiency-hub/
├── index.html          主页面（已加入同步模块）
├── sync.js             云端同步模块
├── manifest.json       PWA 配置
├── tools/              14 个工具页面
└── server/
    ├── server.js       同步服务器
    ├── package.json    依赖配置
    ├── 启动同步服务器.bat  启动脚本
    └── sync-data.json  同步数据存储（自动生成）
```

## 同步原理

1. 所有数据仍保存在浏览器 localStorage 中
2. 同步模块监听 localStorage 变化，自动推送到服务器
3. 服务器按"最后写入获胜"策略合并多设备数据
4. 定期从服务器拉取其他设备的更新

## 注意事项

- 服务器需要保持运行，关闭后同步暂停（本地数据仍可正常使用）
- 如果更换 WiFi 网络，IP 地址可能变化，需要用新地址访问
- 原始应用地址（agentos-app.net）不支持同步，请使用本地服务器地址

# 个人效率中心 · 统一工作台

14 个工具整合在同一个工作台，数据保存在浏览器 localStorage，通过 **GitHub Gist** 在手机和电脑之间手动同步。

在线地址：`https://wyting1234.github.io/efficiency-hub/`

## 云端同步（手机 ↔ 电脑）

同步是**手动**的「上传 / 下载」，每次覆盖前都会弹窗确认，不会在不知情的情况下覆盖数据。

### 首次配置（只需一次）

1. 生成 Token（勾选 `gist` 权限）：
   https://github.com/settings/tokens/new?description=efficiency-hub-sync&scopes=gist
2. 打开应用 → 侧边栏底部「云端同步」（或仪表盘底部的同步状态条）→ 粘贴 Token → 保存并连接。
3. ⚠️ **手机和电脑必须使用同一个 GitHub 账号的 Token**，连接后界面会显示账号名（如 `已连接 @wyting1234`），两端账号一致才能同步。

### 每次同步

- **上传**：在数据「源头」设备上点「⬆️ 上传到云端」，把本机**新增/修改**的数据补充到云端（只传变化部分，速度快；不删除云端已有数据）。
- **下载**：在另一台设备上点「⬇️ 从云端下载」，用云端数据**整体覆盖**本机（会确认）。
- 想让两端一致：源头端上传 → 另一端下载。
- 每次上传/下载完成后，页面顶部会弹出**成功/失败**提示，明确告知结果。

### 更新后看不到新版本？

GitHub Pages 有缓存，请**强制刷新**：电脑 `Ctrl+F5`，手机清除浏览器缓存或换浏览器打开。

## 同步原理

1. 数据全部保存在浏览器 localStorage 中
2. 上传时只把本机**新增/修改**的数据键补充到云端（增量合并，不删除云端数据）
3. 下载时读取同一份 Gist，整体覆盖本机
4. 两端通过「查找同名 Gist」自动连到同一份云端数据（即使旧版本留下多个同名 Gist 也会收敛到同一份）
5. 面板会显示云端数据概况（键数、更新时间、账号），方便确认连的是不是同一份

## 注意事项

- Gist 单文件上限 1MB：如果工具里存了大量照片（base64），可能超限，上传前请先「导出备份」
- Token 只保存在各设备浏览器本地，不会上传到云端数据里
- 所有数据以本机 localStorage 为准；未同步前换设备不会自动带数据，需手动上传/下载
